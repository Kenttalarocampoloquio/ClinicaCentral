# ClinicaCentral

A desktop application for managing clinic operations, built with C# as a final project in Object-Oriented Programming.

## Built With

- C# / .NET 10
- WPF (Windows Presentation Foundation)
- [MySQL via Laragon, if you add the database]

## Getting Started

### Requirements

- Windows 10 or 11
- [.NET 10 SDK](https://dotnet.microsoft.com/download)
- [Laragon](https://laragon.org/) with MySQL running (if the project uses a database)

### Run the project

```bash
git clone https://github.com/Kenttalarocampoloquio/ClinicaCentral.git
cd ClinicaCentral
dotnet run
```
